# Alevel_courswork_rpg_game
This is the code and a large write-up for my A-Level coursework that used a huge amount of code, time, and determination to complete while ill.

It includes ray tracing for enemies to decide whether the player can be seen, terrain generation using the same basis as Conway's Game of Life—cellular automata—and procedural animation for the spider boss using circle math and a self-made algorithm, as well as a quicksort algorithm.

Ultimately, this helped me earn an A in A-Level Computer Science and gave me a profound insight into creating large projects.
